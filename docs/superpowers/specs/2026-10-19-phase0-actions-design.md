# Phase 0 原版动作批量探针设计

> 日期：2026-10-19｜状态：按用户继续开发授权实施

用户已授权继续开发并要求合并测试；按 brainstorming 梳理原版契约后直接实施，不重复请求批准。

选择原版 ISEatFoodAction、ISDrinkFluidAction、ISInventoryTransferAction，保留效果与部分消耗规则。相比手写消耗，这能验证实际原版动作；相比直接接全部自理行为，此范围能隔离失败。只使用现有 SP 候选载体，不改变 MP 优先的产品目标。

提供准备物资、单项吃喝/装包/取出/取消、批量测试、报告和清理。批量覆盖物品往返、吃喝实际效果、三类动作中断、重复搬运与结算后观察。所有物资明确为测试夹具，保存引用后清理，绝不取用玩家资产；搬运必须保持对象、ID、耐久与 ModData。当前只验自身背包与主背包之间的搬运，世界容器和生产工单不在此包内。

动作和移动互斥；移动、停止、退场和保存前停止原版动作。NPC 自动喝水覆写为空，仅用于隔离实验；效果仍由原版喝水动作执行。取消吃喝可能保留已发生的部分消耗，不伪造回滚。失败停止批次，保留日志和夹具供检查，不继续把后续项记为通过。

不改任何调试渲染设置。黄色圈未在本包发现；原版视距调试有黄色分支，当前日志亦证实外部 NPCFW 注入仍在运行，具体圈的来源尚无直接证据。
