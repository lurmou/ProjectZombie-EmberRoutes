# 真实容器搬运探针设计

> 日期：2026-10-19｜状态：按用户持续开发、合并交付授权实施

延续用户要求，在已有原版动作验证后提供一次会话可完整测试的真实容器闭环。采用两个玩家显式右键指定的世界容器、一个现有载体和三件专门生成的测试物资。不给未标记容器访问权，不扫描私人物品。每个容器标记使用 UUID，不用运行时对象索引作长期身份；运行时索引仅检查对象仍附着世界。

选择“原版寻路接近 + 原版转移”方案，保留容量与实例规则。直接更改物品容器无法验证真实劳动；自动搬运现有全部物资会扩大资产与权限范围，均不选。提供从源箱取三件物品、运到目标箱、再原样带回的完整 17 步批次，以及取消、报告、清理和解除标签。失效标签、卸载/拆除、容量不足、受伤、外部移动和超时均停止，不继续远程结算；已搬物品留在当前实际容器，可检查后重测。

动作只对本次夹具执行，不动容器原有物资。NPC 主背包、源、目标中每件只能出现一次，必须保留对象、ID、耐久、名称和 ModData。世界容器动作仅在该实例抑制玩家 loot UI 选择分支，不全局替换原版动作。动作/移动只由一个批次持有；旧吃喝测试与搬运互斥。

本包仍是 SP 候选验证，MP 返回不可用；下一关口仍是专服模拟与同步，而非自动把产品改为 SP。标签是诊断会话的绑定，尚非完整领地权限或跨重启业务账本。
