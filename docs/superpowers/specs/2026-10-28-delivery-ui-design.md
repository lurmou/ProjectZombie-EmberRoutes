## 原生输入证据与方案

当前安装 JAR 的 UIManager.updateMouseButtons 只向根 UI 发 onConsumeMouseButtonDown；UIElement 的额外 onMouseButtonDown 不递归派发给嵌套 ISUI 控件，且只给 Lua 传按钮号。不能把 Grid/CachedList 上设置 wantExtraMouseEvents 当作实际收到中键的证据。

使用原版 ISInventoryPage/ISCollapsableWindow 已用的 isMouseButtonDown，在活动仓储页 update 中仅观察中键上升沿；只有当前可见、未被遮挡的库存控件 isMouseOver 命中且无弹窗/展开菜单时处理，坐标来自该控件 getMouseX/getMouseY，列表沿原版 rowAt 计入滚动。隐藏/关页不注册全局事件，不拦截游戏其他按键；按住/从外拖入/切页不重复加购。去掉旧的子控件额外鼠标旁路，避免双触发。
