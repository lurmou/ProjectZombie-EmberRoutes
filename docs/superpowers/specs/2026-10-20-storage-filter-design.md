# 0.7.0 多选存储过滤器

依据：2026-10-20读取唯一在线需求v3.2，第3.6节；取代0.6单选用途标签。最新正文/差异归档于reviews/2026-10-20，仅审计快照，在线文档仍是唯一需求来源。进度保留本地，SP优先决定不变。用户授权继续开发，当前代理顺序实施。

方案比较：在旧tag列表继续加菜单难以表达组合与例外；直接做完整据点仓储面板会混入尚未实现的领地；本轮采用独立过滤领域模块、树状配置面板、原版容器栏入口，复用已有任务执行器。

配置格式format=1、enabled、private、groups、types。大类与子类规则逐级覆盖，具体fullType规则优先；未配置、格式未知、私人均拒绝NPC读取和写入。读权限不按职业限制，允许从已配置箱拿取实际物品；过滤规则限制存入，避免错放物品无法取回。现有显式路线只规划目标允许的原物品；效果前再次检查，过滤修改导致暂停而不替换/丢弃货物。未实现效用层自动取食或自动全仓分拣。

分类按原版属性和DisplayCategory，保留未知other类并支持注册适配规则；不能承诺任意第三方自定义物品必然识别正确。食物分易腐/耐存，军械分枪械/弹药/其他；具体物品按fullType允许/禁止。面板呈现当前容器可见类型和已保存例外，不枚举全游戏物品数据库。配置克隆/验证有界，存档只写标量。旧标签读取时映射到过滤配置，旧任务/NPC/物品ID不变。

面板从ISCollapsableWindow派生，列表与按钮按字体及容器尺寸计算布局；选择只改草稿，应用才提交本地权威验证。显示来源箱与状态，提供隐私/参与存储、大类与子类/具体物品切换、全选/清空与应用/取消。鼠标、键盘与手柄操作均提供路径，实机未验不宣称已兼容。

不替换原版文件：包装已加载ISInventoryPage.addContainerButton返回的按钮，保留原右键逻辑，再从getPlayerContextMenu追加入口；按钮池每次绑定时更新。角标按配置变更与按钮重建事件计算缓存，render只绘制预计算的图标/色块，不扫描库存或查询分类。CleanUI等其他UI实机兼容独立验证；不具原版返回契约时不强行接管，世界右键入口保留。当前仅主容器，副格明确拒绝，避免误配置主格。

本轮不实现新版其他新增系统：据点解散/热度/活动、感染诊断、生产维保、硬通货、商队损耗、战术轮盘和聚合仓储列后续待办。0.6仍未实测；0.7本地检查不能替代原生动作/存档/UI实测。
