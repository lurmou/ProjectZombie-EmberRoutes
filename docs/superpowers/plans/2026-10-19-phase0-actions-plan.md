# Phase 0 动作测试包实施计划

> 日期：2026-10-19｜状态：实施完成，待用户实机测试

**Goal:** 一次游戏会话可测试原版吃、喝、原实例搬运、中断与重复执行。

**Architecture:** Java 提供受限 SP 载体访问与生命周期动作停止；Lua 适配原版动作，独立状态机组织批次、超时和断言。测试夹具与玩家资产隔离。

**Tech Stack:** B42.21.0 / ZombieBuddy 2.3.4 / Java 17 bytecode / Lua 5.1。

按用户授权直接顺序实施；不启用子代理。

- [x] Java：访问权限、移动互斥、退场停止、禁用探针自动喝水。
- [x] Lua：夹具、原版动作与批量状态机；菜单、双语、状态日志。
- [x] 检查批次完成/失败/取消/超时；构建、Lua preflight、文档链接检查。
- [x] 0.2.0 包与集中测试说明；实机未运行须明确标记。
