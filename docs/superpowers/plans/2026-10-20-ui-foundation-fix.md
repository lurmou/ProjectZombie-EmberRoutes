# 0.7.3 UI基础层与中文重叠修复

日期：2026-10-20；状态：实施与本地检查完成，实机待验。

用户指出上一版界面重叠，并明确UI基础要求为在线v3.2第11节。此轮由主代理直接实施，不派子代理。在线文档本轮重读哈希仍为794B68E2357A42451BA76DED8B266E707B94FD1C390ACAEE47AFF5207A2C9BA4。

## 已复现原因与范围

原UIFlow使用UTF-8字节正则，游戏Kahlua以Java字符处理字符串，正则丢弃中文；标签空了以后行高只剩padding，方框互相覆盖。标题和直接绘制的“跟随分类”不走换行所以仍能出现。使用安装JAR和stdlib.lua真实运行时已复现“Chinese label characters were lost”。旧替身测试用英文键名，没有覆盖实际中文，也没有覆盖真实VM语义。截图中的容器悬停中文丢失同样受影响。

这是批准的筛选窗口修复和用户明确UI工程约束的落实，不增加据点聚合/BOM/HUD业务。仓储容器保留原名，在悬停追加用途；没有需求批准自动改名，不写物理容器名。

## 实施顺序

1. UI/Text.lua：Kahlua/标准Lua都能保留Unicode的分段、显式换行和有界窄宽处理；UIFlow保留兼容入口。先用真实Kahlua复现失败，再验证修复；中文/混合/换行回归不能仅用键名。
2. UI/Layout.lua提供相对bounds、padding/margin/gap与basis/grow的row/column布局；UI/State.lua提供setState、变更订阅/释放；UI/FilterList.lua负责筛选行模型/绘制与生命周期。筛选Panel仅组装、输入和提交，不保留巨型行绘制函数。文本布局与状态只在变化时重建，绘制不扫描业务数据。
3. 主窗口使用PZ暗色高对比背景，最小行高保护方框、字体和间隔；容器tooltip保留原名和完整中文用途。准确记录“基础已开始复用”，不宣称整个第11节或完美跨分辨率已验。
4. 真实Kahlua运行实际CN文字与Panel布局验证；可捕获绘制命令形成非游戏渲染预览，明确与实机分开。相关Lua、构建、preflight、发布/文档检查，打包0.7.3，更新本地待办/测试；实机仍待用户确认。

## 验收

每个非空中文label被完整保留；可见行高度至少容纳字/框，滚动区不溢出底部；设置、状态和图标仍按事件刷新。取消无业务写入，异常不通过空字符串默默掩盖。1080p/2K/4K和大字体做布局逻辑检查；实际游戏缩放、CleanUI和GPU字体观感未运行前不写通过。平滑动画、其他原子组件、聚合面板及HUD仍在待办，不能把这次基础修复标为全套UI完成。
