# 原生 QA 最小闭环实施计划

目标：交付可由脚本/主菜单启动、在隔离世界运行并返回可信结果的原生测试。
设计：[原生 QA 设计](../specs/2026-11-12-native-qa-design.md)。用户批准直接设计执行；本会话自行实施，不安排子代理。整组实现后集中验证。

1. [ ] Java：QaFileProtocol（严格命令/原子结果/序号/运行指纹）与 QaBridge（QA 专用 Kahlua 适配）；Main 条件暴露，生产桥保持不变。最小测试覆盖重复/错 runId/未知命令/坏文件/结果身份。
2. [ ] QA 模组：NativeQaSession（建/载固定 Sandbox 与生命周期）、NativeQaRunner（真实服务装配及移动/取消/actions 场景）、入口事件。使用生产任务协议，不注册新身体执行者。
3. [ ] UI：QaLaunchButton 只消费 Session 服务；qa 原生场景复用同一组件。CN/EN 键与预览工具登记。
4. [ ] PowerShell：run-native-qa 创建有标识的隔离目录，复制固定构建及必要依赖，生成启用列表与 session/command，使用安装版 Java+ZombieBuddy 启动；支持新建/复用、发送命令和有界等待，保存完整日志与指纹。不改 Steam 配置或用户缓存。
5. [ ] 版本 0.29.60，集中构建、相关协议/场景逻辑检查、PZ lint/LuaLS、CN/EN 原生截图；然后自主运行原生 smoke/actions 与退出重进。实际失败持续诊断，不放宽生产守卫。
6. [ ] 更新 INDEX/BACKLOG 和实际证据；按真实覆盖分别列通过、失败、未验证。不得把加载成功记为 NPC 功能通过。

重点审查：旧 command 重放、取消到一半、原件责任未结清、加载到非 QA 世界、构建与运行 JAR 不同、建档/载档过程中异常。所有异常保留来源与现场。
