# 协调链路重复工作清理

沿用用户批准的整体优化及[唯一架构](../specs/2026-10-22-npc-behavior-architecture-design.md)，不改变领取/身体/原件权威。

- [x] JobStore 暴露现有普通任务计数，派工不再每角色遍历全库。
- [x] 普通发现中将刚取得的资格结果直接传给决定步骤；在途结果仍重新验证，不跨tick缓存资格。
- [x] 公共对账仅在有Job链接时构建制作索引，无公共工单且无搬运时清理直接返回；复用内容完全匹配的责任表。
- [x] 控制器增加只读标量状态查询，减少运行器重复快照分配；公开快照隔离不变。
- [x] 定向回归、完整门禁、构建与归档一致性检查；游戏目标仍须实测。
