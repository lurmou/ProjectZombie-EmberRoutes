# UI可用性修整

日期：2026-10-24。状态：本轮现有制作/搬运界面可用性修整已构建0.23.1；实机未验，完整需求缺口见[记录](../../reviews/2026-10-24/ui-usability.md)。

依据在线11～11.4及已确认settlement-ui-design：先解决真实数据、人员身份与物料名称，再修优先级操作、错误反馈和布局。用户已授权整组改善，保留现有并行改动。

1. 共享显示名称适配：优先原版人物姓名，离线保留已观察姓名，界面不输出npcId。
2. 搬运记录保存物品类型元数据；旧记录按有限预算只读观察原件，未知明确显示未识别，编号不代替名称。
3. 人员优先级左右键双向，列头明确选择目标值后批量，按预期修订号提交，逐人错误反馈；移除假健康。
4. 防御未接后端显示未知并禁用假操作。复核公共预检、草稿退出和生命周期。
5. 双语、相关Kahlua、preflight、构建，更新准确验证边界。完整技能/床位/战备业务不凭UI伪造。
