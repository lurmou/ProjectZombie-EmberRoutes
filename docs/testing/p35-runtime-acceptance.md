# P3.5 单人集中实机验收

> 适用：0.26.0开发包；当前未运行本清单。宿主替身通过不表示原生动作、效果或保存通过。
> 设计：[P3.5设计1.1](../superpowers/specs/2026-10-24-p3.5-leisure-social-fitness-design.md)；证据：[本轮实现](../reviews/2026-10-24/p35-leisure-implementation.md)。

## 准备

使用当前安装PZ42基线及ZombieBuddy，在既有单人存档中选择已登记据点和HOLD待命成员；至少两人用于社交。工作优先级只控制现有制作/搬运，闲暇不另设矩阵列。P2/P3未验收问题仍按原清单保留。

据点登记STORAGE图书容器，放入有原版消遣收益且该NPC未读的小说/报刊。让一名Smoker成员自身主背包持真实单支香烟和其原版要求的可用火源。锻炼要求双手空、身体健康、低疲劳、足耐力且无当前/待发作酸痛；不会自动卸武器。没有满足条件的活动时允许待命，不应为测试凭空造物或改属性。

0.28.1沿用0.27.0当前格式存档；旧世界仍需新档。扩展JAR已变化，完全退出游戏再启动以加载同版桥接；不能只重载Lua。升级不会自动将WAIT改为驻扎。

## 连续流程

1. **无活生活**：暂无可执行工单，两名成员以SETTLEMENT驻扎生活在所属据点。观察人员详情/工单监控中的具体状态，等待出现借原书阅读、观察/散步、符合条件的吸烟/锻炼或双人接近与交流。活动有冷却，不保证每次立即选中；观察不冒充完成劳动，也不额外加身心收益。
2. **真实就座与慢发现**：0.28.1重点核对不同朝向椅子、多格床/沙发的精确落座及起身；散步和赴窗边观察之间应有明显停留，不能连续走来走去。拿书后附近有空座时优先坐读，无座/不可达则站读；读完先起身再归还同一本书，跟随中断后座位释放而书仍待归还。有座位时核对走近、坐下、保持、起身；没有坐姿数据/不可达的家具应退避并选择其他活动。图书箱较大或某工单未加载时仍可短暂观察，不能将“正在评估”误称工作已完成。普通观察不再连续站立10游戏分钟。记录人员详情的等待原因，SELECT与ACTIVE分开。
3. **工作与自理中断**：活动中创建确实具备技能、材料和设施的工单，核对先停止旧活动、原件需归还时先归还，再正式认领。记录发现/请求停止与实际停稳/开工的各自时长；不能要求全部在3秒内。饥渴/疲劳和玩家跟随指令分别应结束闲暇，服从既有自理与上下文。
4. **双人社交**：观察各自移动至同层、无遮挡且不堵门的站位，面对同伴、手势和短语；隔墙/跨层不应直接交流。一人改跟随、离开、遇危险时，另一人结束/撤离，不无限等候。允许找不到同伴时回退独处；不要求每轮挥手告别。
5. **真实效果与原件**：阅读沿用个人原版页数/效果并归还同一书。吸烟开头耗火源，提前停止保留实际消费结果；结束仅消费一次真实香烟。锻炼核对原版经验与耐力变化，之后核对延迟负担；原武器不得丢失，NPC结束动作不改变玩家倍速。动画存在不能代替效果核验。
6. **保存重进**：分别在阅读、吸烟开始后、锻炼、社交交流/结束时正常保存再进入。没有旧对话重播、额外经验/收益或原件复制；原件借还责任继续。未明提交显示待核对而非自动重放。此项不等同强退或崩溃事务验证。

## 异常与性能

在合适测试存档中验证玩家移走原件、拆除观察门窗、接近不可达、同伴失联，以及两人竞争一本书。NPC应停止/有限退避并保留未结责任；不传送、不按类型造替代品、不因无效原件卡住另一人的身体。

多NPC另行记录CPU、扫描/寻路量与工作响应时间；单/双人功能通过不外推人数。若有异常，记录NPC当前状态、触发操作与日志，不要求逐个内部模块重复验收。
