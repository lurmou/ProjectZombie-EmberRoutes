# 0.10.0 仓储视觉集中复测

日期：2026-10-20；状态：新实机待测。

完整退出游戏再启动，确认版本0.10.0；沿用已有据点、容器和NPC，不需要重建探针。

1. 打开据点仓储：检查窗口尺寸、暗色背景、物品图标/名称/数量三列、搜索占位文字和分类。选中物品，右侧应出现名称、总量，以及来源名称、每箱数量、坐标与楼层。常见原版物品应有图标；未知/缺失模组图标使用占位。技术ID仅在悬停详情，不混入容器显示名称。
2. 搜索中文或当前游戏语言的物品名，也可搜索fullType。检查无匹配和首次盘点的空态，点击帮助阅读覆盖范围，关闭帮助及窗口。悬停来回移动不能出现左上角虚影，关闭后不能留下Tooltip。
3. 在第二页选中中间物品并滚动，让NPC连续存取：未变行、选中、页码和滚动位置应保留；受影响数量暂为“...”，盘点后补齐。顶部统计保持固定位置；隐私/停用或读取失败仍应清除旧数量。
4. 若方便，换英文或大字体，关闭重开后检查按钮、数量列和两栏是否重叠；键盘上下选择、左右翻页、Esc关闭，手柄X刷新/Y分类/肩键翻页/B关闭沿用旧入口。玩家自己改动物品后仍需手动刷新。

本轮首次正式视觉样式建立在原生ISUI和已有脏数据投影上。实际GPU绘制、游戏缩放、物品贴图及其他UI模组交互尚待实机；本地布局捕获不能替代上述检查。
