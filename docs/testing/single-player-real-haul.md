# 0.6.0 容器标签与真实搬运集中测试

日期：2026-10-19。本版实机未验证。先完整退出游戏再启动，确认日志EmberRoutes v0.6.0；沿用[探针安装与开关](phase0-carrier.md)。[测试包](../../build/packages/EmberRoutesProbe-0.6.0.zip)及本地mod已更新，不要求清空旧存档或日志。建议用已备份的测试世界。

## 准备

右键EmberRoutes → **仓库与实际搬运**。新菜单搬真实物品，不生成测试夹具；与旧“搬运测试”分开。准备两个相距约8至12格、可接近的木箱/货架，玩家在NPC附近16格内。两箱分别设收货、工具等合法用途，在各自子菜单选择本路线源箱/目标箱。

**本版按你指定的路线搬源箱全部合格物品，标签不自动分类。** 最多30件顶层实例；收藏品、装备、包和探针样本/夹具跳过。不递归翻包，仅支持世界对象主容器；冷冻副格、尸体、地面包、车辆未接入。不要用整箱贵重私人物品试验。

## 按顺序集中测试

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 未标记/私人箱尝试选源箱 | 拒绝访问，不动库存 |
| 2 | 设置两端合法标签及路线。源箱放3件普通物品（含改名或改变耐久的物品），再放收藏品和包。目标箱留一件无关物品。开工，完成后打印任务状态 | DONE，3个原ID到目标；收藏品和包留源箱，无关物品不动。日志列各ID的DESTINATION |
| 3 | 再点续工和开始，随后清除任务 | 已完成任务不重放、不建第二单；清除只清任务，不删物品 |
| 4 | 放下一批，开工；NPC拿货后暂停，打印状态确认至少一项NPC；尝试清除任务及删除NPC | 带货保护阻止清除/删除；货留身上，续工后先交付原货 |
| 5 | 下一批带货途中正常保存整个世界（不退出） | 任务暂停、队列清空、NPC检查点保存；打印位置可能为SOURCE/NPC/DESTINATION。显式续工，不回滚/重造物品 |
| 6 | 下一批带货时正常保存退出，完整退出游戏重启同一世界 | NPC恢复，标签/路线和暂停任务保留，不自动开工。打印位置再续工，原ID送达；重复续工不复制 |
| 7 | 一批途中靠近箱子，将源箱/目标箱设私人或清除用途 | 暂停，未生效动作不得拿/放；已拿货留NPC。恢复合法标签再显式续工 |
| 8 | 目标箱装满后开工，或NPC拿货后装满目标 | 提示箱满，未拿的留源箱、已拿的留NPC；腾出空间续工 |
| 9 | 暂停后，玩家移走源箱尚未拿取的一件物品再续工 | 缺失不补发；若NPC已有货，先送完已有货再暂停缺失项。放回原物品可续工；NPC无货时可清除剩余任务 |
| 10 | 一批途中下达跟随/待命/移动，再续工 | 工作暂停，只有一个执行者；续工重新接管，不重放旧动作 |
| 11 | A世界保存暂停任务，进空B世界打印状态，再回A | B无A的任务/路线，A仍可恢复原任务；不能用同世界反复打印代替 |

每批完成后先清除任务再新开一批。报告会写任务ID、NPC UUID、两端ID及各物品位置，单独STARTED不算通过。不要求重跑旧17步搬运和旧12步存档；保留日志，报告出问题的步骤即可。

无带货时明确删除NPC会一并取消其任务记录，货物留在原容器，避免新NPC被旧任务身份锁住；有货时删除仍被阻止。

## 恢复边界

拆除/卸载、重复ID、物品进入NPC嵌套包时暂停，不猜测新物品或另选箱子；先恢复物理条件。无法确认原NPC时禁止清除及删除，请先恢复并靠近原NPC。带货时删除只在当前UI入口阻止，主体死亡和其他模组删除不具无损保证。

原版食物腐坏及搬运动作的厨师标记等自然变化仍保留；同一实例不等于每个字段永不变化。强退、断电和世界文件回滚不保证无损。自动分类、多NPC、全图库存及商队结算见[后续扩展设计](../superpowers/specs/2026-10-19-real-haul-design.md)，本版未实现。
