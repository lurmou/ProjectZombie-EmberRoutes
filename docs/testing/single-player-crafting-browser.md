# 配方浏览与委托制作

适用0.21.0。重启加载新版本，打开据点管理→制作→配方。

搜索配方或产物，用分类缩小范围。默认展示当前执行机制可接的配方；“全部机制”允许查看尚未支持的条目，不会因此开启其制作。首次目录分片加载时会显示载入状态，尚未搜到不一定代表配方不存在。

选中配方后，右侧物品槽显示整单产物、消耗原料、复用归还工具及“可取/所需”。输入目标件数，批次和多出数量自动更新。手持配方没有平台设置；表面配方使用已登记平台，无候选时点登记帮助，按现有世界右键“用于据点制作”登记后返回。选择执行人，等预检完成后下单。可点击输入槽展开替代品，点击具体物品跳到仓储搜索。

缺料时明确显示待补料操作，建立后不会自动无限重试；补齐分类箱后到工单视图继续。NPC缺知识但技能够时可传授，再重新核对。大数量超出预检预算显示未知，实际执行仍受逐批库存、负重和路线门禁约束。

日常只需合并观察：搜“木板”选锯原木目标1，确认手持无平台、产出3木板、原木1和锯1；换木叉确认出现平台要求；下单后切回配方，搜索/数量应保留，工单可独立暂停/继续。无需重建据点或重跑全部历史测试。

这些新UI/目录/预检尚待实机确认。[实际检查与限制](../reviews/2026-10-22/probe-0.21.0-crafting-browser.md)区分静态、替身与实机结果。
