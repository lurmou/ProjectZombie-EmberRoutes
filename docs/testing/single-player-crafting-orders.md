# 单人单件制作与续工

> 2026-10-21｜0.18.0｜[实现记录](../reviews/2026-10-21/probe-0.18.0-crafting-orders-resume.md)。0.17.3正常制作已获用户实机确认；新增保存续工和正式UI尚待确认。

沿用现有据点和分类箱：小木柄、锋利刀具、木制餐叉分别有匹配的共享STORAGE箱，不使用私人/排除箱，不读玩家库存。只检查箱子/NPC主容器，受保护物品不参与。玩家和NPC在同一有权限据点，NPC健康至少95、有负重与可达路径；雕刻至少2级且学会配方。传授需要玩家已掌握配方，不自动提升技能。原版配方名“雕刻木制餐叉”，成品名“餐叉 (木制)”。

1. **正式入口**：右键原版有效桌面/平台 → 余烬商路 → 用于据点制作。制作页选择NPC和平台，必要时传授，再点“下单制作”。无需砧板、管理终端或生产专用箱；已有平台之后可直接在据点窗口的制作页选用。当前仅制作一把木制餐叉。
2. **保存不退出**：取料或制作途中正常保存；保存完成、游戏继续更新后应自动续工。未完成的制作动画可能从头播放，但同单只制成一件，产物和原刀分类入库。保存失败保持暂停，处理问题后可手动继续。
3. **手动/读档继续**：点暂停后可点“继续工单”；保存退出重进后，打开制作页点继续。已制成的单只交付、不重做。若不想继续，点“取消并归还”，现存原件分类归还。

旧版暂停单若尚无平台定位，第一次继续前先在原平台右键选择“用于据点制作”。缺料补到现有分类箱再下单；未认领原件的找料失败不形成持久队列。平台未加载/更换、原件缺失、私人或分类规则变化时会暂停，不能用同类型替代。结果待核对的单会阻止重复制作，保留CRAFT日志，可尝试归还现存原件；不要反复新建单。

普通入口无需开启Debug菜单，仍沿用当前载体探针沙盒开关。制作接管该NPC后，要恢复自动物流可在物流页重新启用；关闭/切走制作页不停止后台。强退崩溃一致性、批量/BOM和联机仍未实现或未验证。
