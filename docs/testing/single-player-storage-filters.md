# 0.7.3 仓储界面修复与集中复测

日期：2026-10-20。用户反馈0.7.1测试还行；0.7.2实机发现中文缺失/条目重叠，0.7.3修复待验。完整退出并重启游戏，确认EmberRoutes v0.7.3，沿用[安装/探针开关](phase0-carrier.md)。本地mod和[测试包](../../build/packages/EmberRoutesProbe-0.7.3.zip)会同步更新，不要求重建世界或清空日志。0.6未验项目合并到本次，不单独重复旧单选标签步骤。

## 新入口及规则

当前补丁0.7.1修复完成任务阻挡下一单：完成后向源箱放新物品直接开始，无需先清除旧记录；续工仍只针对原任务。保留旧完成任务即可升级。见[修复和短复测](../reviews/2026-10-20/probe-0.7.1-task-rollover.md)。下方0.7.0原测试流程仍适用，完成任务的“清除”改为可选。

在原版右侧战利品容器栏，右键木箱/货架的图标，原菜单之外应有“仓储用途与物品筛选”。备用入口：右键世界箱子 → EmberRoutes → 仓库与实际搬运 → 对应箱子 → 存储过滤设置。

配置只影响NPC，玩家正常拖放不受限制。勾选大类包含子类，子类可例外；具体物品规则优先。具体类型循环为允许→禁止→跟随分类；只列当前容器中最多128种类型及已有例外。要提前设置不在目标箱的某物品，可先手动放一件进去，设置后再拿走。没有配置/关闭参与存储/私人均禁止NPC读写；没有选接收类别的已配置箱可取出已有物品，但不自动接收新物品。

鼠标点击切换，应用才写入；取消不生效。键盘方向键导航、空格切换、回车应用、Esc取消；手柄方向导航、A切换、X应用、B取消。主图标整枚替换：单类显示分类图、多类或允许的具体物品例外显示混合仓箱、私人/停用显示锁；空规则显示通用柜。悬停保留容器名并显示分类/例外计数，不再画微小角标。0.8.1起主容器和冰柜副格分别配置、独立登记；车辆/地面包/尸体仍不接。请不要用贵重库存试验。

## 0.7.3修复优先复测

完整重启后用原存档：打开筛选窗口，分类、物品与说明应完整显示，方框/条目不能重叠；滚动到底再返回并切换大字体。容器悬停应保留原名并完整显示用途，不应只剩容量数字或斜线。通用应用/取消使用游戏原版翻译键，文字跟随当前语言，英文也可验证。

再检查应用/取消、过滤类别和连续两批开工即可；不用重跑全部保存/故障测试。本轮[技术证据](../reviews/2026-10-20/probe-0.7.3-ui-foundation.md)与[UI基础边界](../ui-architecture.md)已更新。

## 图标与输入检查（可合并）

1. 目标只允许食物并应用：侧栏整枚图标变为冰箱；再加工具，变为单枚仓箱。悬停应显示原容器名及已选类别。
2. 设置私有或关闭访问：图标变锁，NPC仍拒绝使用；恢复启用且取消私有，图标立即回到用途图。
3. 打开筛选窗口：检查方框、根分类色条和子类缩进。点击具体物品依次看到“允许 / 拒绝 / 跟随分类”；物品按当前游戏语言显示原版名称，取消后现场规则不变。
4. 切换附近箱子及自己的背包/地面物品，必要时走远再回来：主图和悬停不能串箱，背包/地面仍用原图；原有选择、重命名、锁定效果保留。
5. 调大UI字体再打开窗口，检查分类和按钮、失败提示不重叠；用方向键+空格操作并应用。如使用英文界面或手柄，可一并测；没有则记未测。
6. 保持原源箱和目标箱，按新规则搬运，完成后直接放下一批再开始。无需清除旧任务；规则不允许的物品留源。正常保存重进后配置和主图仍正确。

本轮不要求重复全部旧故障场景。下表作为原0.7基础流程留存，尚未覆盖的边界可按需补测。

## 原基础集中测试

准备一个NPC和两个间隔8至12格、可接近的箱子；玩家保持NPC16格内。源放罐头、易腐食物、工具、弹药等几件真实物品；目标保留一件无关物品。新系统不会生成夹具。

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 从原版容器栏右键打开；再从世界右键打开；开关面板并观察原菜单 | 面板出现，原重命名等菜单保留；普通背包和副容器不应误打开主格设置 |
| 2 | 源箱设置参与存储并全部允许。目标选食物，再取消易腐，应用 | 食物子类呈部分选择；目标主图标更新，只允许耐存食物入库 |
| 3 | 在仓库菜单选择源/目标并开工，完成后打印状态 | 只搬目标允许的原物品；鲜食、工具、弹药留源。已有无关物品不动，名称/耐久随原实例保留 |
| 4 | 清除已完成任务。目标同时允许工具/军械，临时放入一件物品设置其具体类型为禁止，再拿回源箱并开工 | 大类可多选；被具体禁止的类型留源；将它改为继承后按大类规则；不需要职业解锁 |
| 5 | 目标设私人或关闭参与，尝试选路/开工；编辑后取消 | 私人/禁用拒绝访问；取消不写配置。取消私人后仍保留原选择草稿逻辑，需应用才改现场 |
| 6 | 开始一批，NPC拿取或交付途中将目标排除此物品/设私人 | 动作不再违法拿放；已拿货留NPC，任务暂停。恢复允许规则后显式续工，原ID完成；带货时不能清任务或删除NPC |
| 7 | 一批途中正常保存不退出，打印状态后续工；另一次带货保存退出、完整重启并回原世界 | 配置、具体例外、任务和原NPC恢复；不自动重放动作，显式续工后匹配原ID交付。空B世界不应带入A配置/任务 |
| 8 | 目标装满，或NPC带货后装满；暂停时移走后续源物品 | 箱满暂停，腾空间续工；缺失不补发，已有货先交付再报缺失。原物品放回可续工 |
| 9 | 调整游戏UI字体/缩放再打开；用键盘/手柄导航切换与应用/取消 | 面板可用、不越屏，导航不误勾选；状态只在应用时提交。没有手柄则记录未测，不必购买/模拟硬件 |
| 10 | 切换附近不同箱子让侧栏按钮复用，观察主图标；如原本启用CleanUI，保留它测试 | 主图标不串箱；取消私人/改分类立即更新。CleanUI入口异常时记录，并用世界右键备用入口测试，不能把备用入口成功算作CleanUI兼容通过 |

不要求重跑旧17步夹具和旧12步存档。本次报告步骤、气泡/画面现象及日志即可。特别是第6/7/8步的实际物品数量/位置是验收依据，单独STARTED或界面勾选正常不足以通过。

## 当前边界

这是可扩展过滤基础加显式搬运路线，还没有自动遍历多仓分拣、效用取食、据点管理搜索面板或BOM生产。原版物品属性与DisplayCategory可分类许多第三方物品，不能推断任意模组必然正确；未知类进入其他，可指定具体类型或注册适配。旧0.6标签会在读取时映射；食品标签变为接收食物，旧任务若不符合新过滤会暂停，不更换或删除货物。

UI原生渲染、CleanUI、存档一致性和性能需要实测。未加载/拆除/被消耗/死亡/外部模组删除或强退不保证无损。背景和语法/逻辑检查不是实机验收。
