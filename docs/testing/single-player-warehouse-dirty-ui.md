# 0.9.1 仓储更新复测

完整退出并重启，确认EmberRoutes v0.9.1，沿用原存档/据点/NPC。包见[0.9.1](../../build/packages/EmberRoutesProbe-0.9.1.zip)。本轮不用重建NPC探针，也不必再重复全部0.9.0步骤。

1. 打开仓储，选择一个靠后的物品；若现成库存有多页，翻第二页并滚动一些。不必为了测试制造大量物品。
2. 让NPC连续搬运几件物品，同时观察两栏：列表不应反复空白，选择、页码、滚动位置不应跳回开头。受影响数量短暂显示“...”后更新；其他行不动。顶部更新状态切换正常，物品真正耗尽时该行消失正常。若原版事件未提供来源，允许全部数量待核实，但列表结构仍保留。
3. 搜索/分类时继续搬运，确认筛选条件保持；悬停数量变化的物品或来源，提示更新而不是左上角虚影。手动翻页仍从该页顶部开始。
4. 把某箱设为私人/停用，旧展示应立即清理，再恢复并刷新；正常保存重进后数量正确。权限变化清理是预期，不能为了无闪烁保留旧私有库存。货物实际入NPC背包期间不算仓储库存。

反馈问题发生的步骤和“整栏空白/数量变化/选中跳动/提示变化”即可；无需清空console.txt。算法和本地验证见[修复记录](../reviews/2026-10-20/probe-0.9.1-warehouse-dirty-ui.md)。实际无闪烁仍待本轮实机确认。
