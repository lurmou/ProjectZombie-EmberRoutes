# 0.11.0 仓储查询与交互集中复测

日期2026-10-20；状态：新实机待测。完整退出重启，确认0.11.0配套Lua/Java；沿用现有据点、容器和NPC。

1. **查询。** 输入物品名搜索，清空按钮恢复结果和第一页。切换名称升/降、数量多少排序；数量独立成列，未知量显示“...”并排最后。底部显示类别和排序条件。中文名称按本地化字符串字符顺序排序，不承诺拼音顺序。
2. **更新时的位置。** 选中一个物品并滚动，让NPC连续存取。默认顺序应保留原页/选中/滚动，未变行不重建；按数量排序时，若选中物品被排到其他页，页面跟随该物品。之后翻页按钮仍须正常。失去权限或读取失败仍清旧量。
3. **来源定位。** 选择右侧来源，点击“定位选中来源”。应提示XYZ，并在对应楼层方格标记5秒；可立即关闭面板观察。标记不传送相机或角色，其他楼层可能被当前视角遮挡。重复定位应替换旧标记；过期后消失。若来源已卸载/移除/私有或超出范围，应解释原因，不标旧坐标。
4. **输入与空态。** Tab切换两栏，Enter从物品进入来源、再Enter定位；搜索框输入时不能触发列表指令，帮助打开时也不能穿透。键盘左右翻页、Esc关闭；手柄左右换栏、A进入/定位、X刷新、Y分类、肩键翻页、左摇杆按下清搜索、右摇杆按下循环排序。未匹配、首次加载、读取错误须分别显示；不可操作的清空/翻页/定位/重复刷新按钮应禁用。
5. **可选性能采样（调试模式）。** 右键模组据点菜单选择“开始仓储CPU采样（调试）”，打开仓储、搜索/排序并让NPC搬几件物品，关闭窗口后从同一菜单“结束并记录仓储CPU采样”。日志只需保留WAREHOUSE_PERF行。每类最多2048样本，达到上限会标capped=true；再次开始会清旧样本，跨世界自动停止。采样默认关闭，正常游玩无需开启。

采样含ui.open（打开）、ui.query（纯查询）、ui.update（快照投影/状态/条目更新）、index.slice（盘点切片）、ui.panel（面板自有绘制提交，不含原生父窗口）、ui.items/ui.sources（列表原生prerender提交）。阶段存在嵌套，不能相加当整帧耗时；avg/max和最近128值p95是CPU墙钟耗时，含采样开销，不是GPU耗时或帧率。实机CPU/GPU性能与实际标记可见性尚未验证。
