> 日期：2026-10-19｜状态：0.2.0 用户与日志确认十项通过；保留作为动作回归说明

0.2.0 十项已完成 [实机验收](../reviews/2026-10-19/probe-0.2.0-runtime.md)。本页保留当时的安装版本及测试步骤；当前 0.3.0 保留相同动作菜单，安装当前整包即可回归，新增内容见 [实体容器搬运测试](phase0-world-haul.md)。

## 使用

1. **完整退出游戏再更新整包到 0.2.0**。当前项目已生成安装内容；如果游戏直接加载本 Workshop 目录，无须再装副本。其他安装方式见 [载体说明](phase0-carrier.md)。确认日志同时出现 `[EmberRoutes v0.2.0] BOOT` 和 `READY`。
2. 临时单机世界，开启载体探针沙盒选项；正常 1 倍速，关闭原版“瞬间动作”作弊。关闭其他 NPC 模组以固定环境。注意：本次日志仍显示 NPCFW 的 Java 注入在运行，禁用模组列表未必会移除其启动代理；本包没有修改你的启动配置。
3. 在附近生成一个健康 NPC，等待停止移动。右键 → **余烬商路：载体探针 → 原版动作测试 → 一键运行完整动作测试（10项）**。
4. 等待头顶显示 `PASSED 10`，或 `FAILED` / `CANCELLED`。一般需要几十秒；单项 60 秒现实时间超时。期间不要暂停、加速或移动 NPC；重复点击只会返回 `BUSY`。第一项失败就停止后续测试。
5. 点击“输出测试报告到日志”。查看 `C:/Users/MuMu/Zomboid/console.txt` 的 `[EmberRoutes v0.2.0] ACTION` 行。保留完整日志即可，无需逐项截图。

## 一键覆盖范围

| 检查 | 通过条件 |
|---|---|
| PACK_INSTANCE | 原版搬运动作将测试铅笔装入 NPC 的测试背包；实例 ID、耐久、ModData 不变，两个容器只有一份 |
| UNPACK_INSTANCE | 同一对象取回 NPC 主背包，检查相同状态 |
| EAT_EFFECT | 原版动作吃掉四分之一基准食物量，食物实际减少且饥饿降低 |
| DRINK_EFFECT | 原版动作喝掉当前水量的四分之一，水量实际减少且口渴降低 |
| CANCEL_TRANSFER | 中途停止搬运，物品仍在原容器且没有副本 |
| CANCEL_EAT_PARTIAL | 中途停止吃饭；按原版规则保留部分消耗，小于本次完整请求量 |
| CANCEL_DRINK_PARTIAL | 中途停止喝水；已喝水量保留，不能继续喝完 |
| REPEAT_PACK / REPEAT_UNPACK | 再次往返，仍是同一个物品，没有重建或复制 |
| IDLE_NO_REPEAT | 结束后观察两秒，食物、水量和容器位置不再改变，原版动作队列为空 |

每次完整批次先清理上一批夹具再生成新的测试背包、铅笔、面包和瓶装水。只改变临时 NPC 的饥饿/口渴测试值，不取用玩家背包物资。NPC 的自动喝水仅在探针类中禁用，避免干扰喝水测量；玩家行为不变。测试后可用单项菜单继续吃喝、装包和取出；物资不足时明确失败，不自动无限补货。

## 同一会话再测的中断情境

先完成一键测试，再用单项“吃测试食物”或“喝测试瓶装水”启动较长动作：

- 动作中点击“取消”或“停止”，确认马上停止，已发生的部分吃喝不会回滚，也不会继续结算。
- 动作中下达“移动到此处”，确认停止动作后才移动；抵达后重新准备物资还能运行。移动会使本次测试失效并清理夹具。
- 动作中“移除”，等待 `REMOVAL_PENDING` → `REMOVED`，观察后续动画和日志；再生成并完整跑一遍。
- 空地、上下楼及被僵尸攻击时移除仍按 [载体说明](phase0-carrier.md) 复测。动作测试检测到 NPC 健康低于 95 会取消，不能把受击取消算作通过。

“清理测试物资”只删除本次夹具引用；若测试包内混入其他物品，或夹具移到未知容器，将返回 `CLEANUP_BLOCKED` 并保留对象。不要把测试背包用于正式储物。

## 结果和边界

`PASSED 10` 是本次运行的自动观察结果，仍需确认动画、玩家输入和界面正常；没有播放动画也应反馈。`FAILED` 后看第一条失败证据；`ERROR` 是局部测试异常，原始原因写日志。取消不会伪装成成功。

本包搬运范围为 NPC 主背包和自身测试背包，**尚不含世界仓库搬运、岗位生产、自动寻食、MP 动作、持久化恢复**。本地构建、纯逻辑及替身测试均不能代替上述实机验证。

测试完成清理夹具并移除 NPC，确认 `carrier=absent` 后再保存/退出。仍使用临时世界；OnSave 清理不是完整存档协议。

黄色圈：本包没有圈、标记或高亮绘制。原版 `Zombie.Render.ViewDistance` 有黄色分支，但本机读取的配置为 false；当前日志也证实 NPCFW 注入活跃。尚未确认你看到的圈具体由谁绘制，不能据此断言沿用了旧代码。
