# 0.8.1 据点与仓储集中测试

日期：2026-10-20；状态：新功能实机待验。完整退出并重启至EmberRoutes v0.8.1，沿用[安装/探针开关](phase0-carrier.md)。[当前包](../../build/packages/EmberRoutesProbe-0.8.1.zip)已同步更新本地mod；可沿用原存档、NPC与过滤配置。

准备：一个有空间的据点位置，范围内两个已启用的仓库A/B（可以有楼上箱子），一个私人箱P、一个未配置箱U；范围外另一个已配置箱O。放少量已知数量的真实物品，已登记容器直接存放（冰箱/冰柜分别配置）；包内物品本版不盘点。以前的箱子可直接沿用，只需用已有过滤面板调整访问开关。

## 一次会话

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 地面右键→EmberRoutes→新建据点；在窗口外世界地面拖拽框选，试取消一次 | 地面范围预览，不生成围栏或家具；取消不保存据点 |
| 2 | 再新建，先框选，再点击名称输入框修改名称，确认范围不变；框入A/B/P/U，自己站在所选范围内，点击应用 | 保存并打开据点仓储；以后地面右键→EmberRoutes→据点仓储-名称；范围外仍显示入口和原因，点击可编辑追加范围；站在范围内才打开盘点，无家具前置 |
| 3 | 看加载/未加载/私有/失效/超限计数及物品/来源两栏；点击某物品 | A/B直接物品按原实例件数汇总；P/U/O内容不计入；来源显示箱子译名/自定义名、箱号、坐标和z楼层。未配置箱U不会被全图发现，不计入候选箱数量 |
| 4 | 输入物品当前语言名称或fullType，切换类别，再清空搜索 | 只过滤缓存，无新盘点等待；来源跟随选中物品。类型多于60时可翻页，键盘左右键也能翻页。分类依据实际物品，不由箱子的接收类别把错放物品隐藏 |
| 5 | 从范围与名称进入编辑，先不重框只改名并应用；再追加一个与旧范围重叠、含新箱子的区域 | 名称更新、旧区域保留、同一箱/物品不重复计数；新区域覆盖所有楼层。多块是同据点并集，不是自动合并两个据点账本 |
| 6 | 将A设私人或停用，回面板观察；再恢复访问。玩家手动拿放一件物品后点刷新盘点 | 撤权后旧汇总撤下，新结果不读A；恢复后可重新盘点。玩家/第三方物品变更本版要求显式刷新，不承诺所有原版事件自动覆盖 |
| 7 | 用原源箱/目标箱开启一批NPC搬运，打开据点仓储观察，再验证完成后下一批 | NPC原实例转移成功后触发盘点失效；搬运中的货在NPC身上时不算仓库存量，交付后重新出现。原任务仍可连续派单，汇总不控制或重复结算物品 |
| 8 | 关闭再打开面板；正常保存退出、重进原世界，站在据点内再打开 | 名称/区域/归属和旧容器配置保留；重新读取当前物品，不把旧快照当真库存；关闭后无持续盘点。正常保存不代表强退无损 |
| 9 | 调大字体/改变分辨率后重新打开；如已有手柄，试方向选择、X刷新/Y分类、肩键分页/B关闭；划区方向/A两角/X应用/B取消 | 无重叠、中文/英文跟随当前游戏语言；鼠标和原右键菜单保留。没有手柄则记未测 |

如自然遇到范围内某箱卸载/拆除，点刷新：应显示未加载/失效，不应把旧内容保留为可用，也不应把未知说成0。没有遇到则记录未测，不用为了此项搬迁大量库存。已有空世界B时可检查B不出现A据点，不必新建世界重跑全部旧NPC探针。

补充冰柜复测：右键原版容器栏的冰柜图标设置食品规则，冰箱主格设置另一规则，两个图标/规则互不覆盖。世界右键的容器子菜单也应分别列出。冰柜设为搬运目标，少量食品入柜后刷新据点仓储；正常保存重进，确认身份与规则保留。新冰柜实机尚未验证。

## 边界

这版为只读盘点，不会远程取放/扣料，不包含包内物品、自动分拣、BOM、商队、防刷新、拆除保护、解散、MP或原版SafeHouse。最多32据点、16块/据点、每块128×128；只是本阶段限制，不是性能实测承诺。不同据点有重叠时不能把其汇总再相加当全阵营资产。

本地标准Lua、真实Kahlua/双语、布局预览和静态检查不能代替上述实机。反馈步骤、窗口现象和日志即可；无需清空console.txt。架构见[基础契约](../settlement-storage-architecture.md)，证据见[实现记录](../reviews/2026-10-20/probe-0.8.1-settlement-input-freezer.md)。
