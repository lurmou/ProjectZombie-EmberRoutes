# P3 人员与实体书研习集中验收

> 0.25.0｜状态：未运行。一次集中核对人员、书籍、工单与正常保存；不把宿主测试计作实机通过。

准备：干净的单人测试场景，创建据点及至少两名HOLD成员；把合适等级的技能书、两人尚未掌握配方的原版杂志和必要材料放入据点已登记且允许存放这些物品的STORAGE容器。未登记书架不会自动取得借阅授权。保留一份读前存档。

| 流程 | 预期与核对事实 |
|---|---|
| 人员详情 | 点选不同人员查看技能、知识分页、情绪；单人优先级与全员矩阵互相同步。关闭窗口后后台工作继续 |
| 缺配方工单 | 玩家可合法创建工单；NPC技能够但未掌握时显示缺知识，不先认领制作；空闲NPC借原杂志研读 |
| 阅读完成 | 原版动作完整运行后该NPC真实学会；原杂志归还同一实例后，工单重新核验并认领；没有短动画解锁或新造书 |
| 中断杂志 | 读完前停止/跟随/取消工单，不提前获得配方；归还责任保留。无正数页数杂志没有伪造页数恢复承诺 |
| 技能书传阅 | 两NPC依次借同一本书；每人从自己的原版页数续读，倍率沿原版规则增长，书不消失 |
| 争用与资格 | 一本同刻最多一人借；文盲、等级不适合、已读完无收益者不领取；光线不足安全停止 |
| 自理与跟随 | 读书时饥渴/疲劳出现先停稳；归还受阻仍保留书并可使用本人主库存物资自理。新跟随指令下短暂自理后恢复跟随，不擅自回仓库还书 |
| 新工作 | 技能书阅读安全片段后重新评估；新工单/本人优先级变化使旧闲暇机会失效，不能抢占正在执行的普通工作 |
| 来源失效 | 借出后原容器满/被移除，尝试授权归还路径；不可归还保留原件与原因。书被玩家移走时不按类型补造、不自动重放未知效果 |
| 正常保存重进 | 分别在移动/借书/阅读中/阅读完成归还前保存重进；页数、知识、书籍原件及借还责任一致，不重复产生学习效果 |

记录角色、书籍原件、读前/读后页数与知识、工单变化及具体失败步骤。强退、跨文件事务、多NPC规模性能和MP另立验证，不在这组通过后顺带宣称支持。
