# 通用物品配方与按量制作

适用0.20.1。重启游戏加载新版本，沿用原分类储物箱及NPC；不要为了测试新建整套据点。普通有效平台右键“用于据点制作”，打开据点管理中心的制作页。手持配方不要求平台。

目前提供7个候选：木叉、木勺、床单绳、锯原木、劈原木、临时帐篷套件、木工具箱（显示名跟随原版翻译，具体ID与结构见[覆盖记录](../reviews/2026-10-22/probe-0.20.1-recipe-coverage.md)）。运行时机制不支持的候选不展示。选择配方、输入数量，选择工人并下单；知识与技能要求按原版。材料来自共享分类箱，不拿玩家背包；产物和工具归入匹配分类箱。页面“已制作”和“已入库”分别计数，目标不会随着物流批次更换而缩小。每批产量不能整除请求时，按整批取整并显示实际目标。

这次日常优先试锯原木目标4件，实际应产出并入库6块木板；方便时试劈原木，柴火与碎木都应分类入库。无须一口气测完7项。多材料/工具可之后顺手试帐篷或木箱。若顺手测试保存，在制作途中保存但不退出，检查同一工单继续且不重复产出。缺料暂停后向原分类箱补料，点击继续工单，保留原进度；无需重下整单。读档或手动暂停后显式继续。

旧格式木叉单仍走旧恢复路径，未结算资产不强制转换新格式。未知制作结果会阻止重做；即使归还可见原件，也不能据此自动清除“待核对”。本轮未实现最低存量、完整配方搜索、BOM或液体/专用工作台制作。

静态及替身宿主检查不等于实机验收，见[实际证据](../reviews/2026-10-22/probe-0.20.0-generic-production.md)。
