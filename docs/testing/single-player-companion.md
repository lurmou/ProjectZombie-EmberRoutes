## 开始

完整退出游戏，使用 **0.4.0 整包**，确认日志 BOOT、READY 都带 `[EmberRoutes v0.4.0]`。如果游戏直接加载本项目 Workshop 目录，已经就位，无需再装一个副本。仍需 ZombieBuddy、载体探针沙盒开关及临时单机世界；安装见 [载体说明](phase0-carrier.md)。

生成一个 NPC。右键 → 余烬商路：载体探针 → **随从指令**。当前只控制这个临时 NPC，尚没有持久招募、战斗战术或正式存档恢复。

## 同一会话集中测试

| 项目 | 操作与预期 |
|---|---|
| 基础跟随 | 点击“跟随我”，正常步行走直线、转弯、绕一个墙角。NPC 应实际跟上；玩家停下后在约两格附近停止，不反复原地启动。首次跟随自动把 NPC 起始位置记为驻点 |
| 原地待命 | 跟随中点击“原地待命”，再走开 5～8 格；NPC 停留，不能自动追上 |
| 设置驻点 | 将 NPC 移到所需的**平整落脚处**并停止，点击“将NPC当前位置设为驻点”；记录的是 NPC 所在位置，而非右键位置 |
| 返回驻点 | 让它跟随到别处，点击“返回驻点”；实际走回，状态应由 RETURNING 变为 HOLD / HOME_REACHED |
| 跨层跟随/返回 | 在正常楼梯建筑中分别上下楼。相同 XY 的楼上楼下不能被当作已经跟上；不要把驻点设在半截楼梯 |
| 跟随转工作 | 跟随中运行旧十项吃喝测试或17步搬运；NPC 应先停止跟随，只有当前工作执行，不抢路径。吃喝的自动测试仍按正常 1 倍速运行 |
| 工作转随从 | 搬运中点击跟随/待命；旧任务取消，已搬的测试物品留在实际容器，可查看搬运报告后清理；不复制、不自动续跑旧工作 |
| 外部移动/停止 | 跟随中使用“移动到此处”或“停止”；随从模式应转为 HOLD，不能马上又拉回玩家身边 |
| 失败与恢复 | 玩家跑到16格以外、设置无法通行的路径或堵门。不能瞬移；超过范围或三次连续路径失败后 BLOCKED。回到附近、清除障碍，再显式点“跟随我”恢复 |
| 删除再生成 | 移除并确认 REMOVED，再生成新 NPC。旧跟随/驻点不能接管新人物；先点返回驻点应 HOME_NOT_SET，重新设置后才可返回 |
| 暂停与移动 | 在跟随或返回途中暂停约30秒，再继续。暂停期间不应走动；恢复后不应仅因这段暂停立刻耗尽原路径20秒时限。原有批量动作测试的60秒现实时间超时尚不适配长暂停，勿用它们测此项 |
| 暂停时移除 | 清理测试物资，暂停，在没有僵尸攻击时点击移除；应从 PENDING 经过静默检测到 REMOVED，而非一直停在同一帧等待。正在攻击/抓取时可 BLOCKED，解除暂停、待攻击结束再显式重试；不要反复点击 |

每个阶段可点“查看随从状态（日志）”。日志关键词为 `COMPANION STATE`、`HOME_SET`、`REPORT`、`MOVE_REFUSED`；路径沿用 `MOVE_TARGET/PROGRESS/REACHED`，移除沿用 `REMOVAL_PENDING/REMOVED/BLOCKED`。保留整份 `C:/Users/MuMu/Zomboid/console.txt` 即可。

## 边界

跟随当前是位置跟随，采用 500ms 决策、3格起步/2格停步滞回、至少1秒的重规划间隔。没有并肩按键镜像、跑步追赶、强制加载或传送补位；超过16格停止，需要你回到附近重新下令。

驻点和跟随命令仅存在当前会话，并绑定当前 NPC UUID。**此包没有角色/库存跨保存恢复**；保存前仍须清理夹具并等到 `REMOVED / carrier=absent`。新增暂停回调不是保存事务，不能保证立即退出、崩溃或系统休眠下完整清理。

只实现单人后端；联机接口保留，MP 仍明确不可用。用户已反馈本轮全部测试通过；直接日志与用户报告的范围见上方实机记录。本地回归与语法检查本身不能替代游戏表现。
