# P2 单人集中验收

版本：0.25.1集成候选｜日期：2026-10-24｜状态：未运行，不能预填通过。

范围和开发侧证据见[P2生活闭环](../reviews/2026-10-24/p2-living-loop.md)。完整重启游戏加载新Java接口；沿用当前有效的新任务存档，不删除原件/旧数据。一次集中测试以下三组，不要求逐内部模块验收。

需求调节使用**已有原版Debug子菜单中的NPC属性面板**，不调玩家面板；该面板已能编辑饥饿、口渴、疲劳和耐力。不要在正式菜单找“自理工单”，个人自理没有公共Order。准备NPC本人携带的安全食物/纯水，以及据点可访问的分类仓储；制作托管材料应另放，确认不被吃掉。诊断夹具标记的食物和水不会成为正式生活候选。

| 一组流程 | 关键观察 |
|---|---|
| 工作/跟随→吃喝→恢复 | 开始一张制作单或携货搬运，NPC取料后将口渴调至0.5、饥饿调至0.5，观察真实消费与同一原任务继续；再在跟随中用个人物资重复，确认不回据点领单。两NPC共用一份原件不重复消费；生产材料不被吃掉。剩余食物、水瓶和原版空容器保留原实例，分类不符时送适合仓储或显示待归还，不凭空消失。 |
| 部分中断/命令覆盖/保存 | 吃喝中途下停止或新随从命令，核对已有部分消费不被补回/重复扣；在自理时暂停或取消原制作单，确认不擅自续旧工。再在自理中正常保存、不退出续玩及正常退出重进，各核对原件、已消费部分和原任务唯一恢复。用户暂停不因读档失效。 |
| 耐力休息/疲劳睡眠 | 安全HOLD下把耐力调至0.15，观察原生值实际恢复；再让饥饿/口渴低于0.2、疲劳升至0.8，观察地面睡眠时疲劳随游戏时间下降。睡眠不应让玩家画面淡出、自动加速或自动保存。中途停止/正常保存应实际醒来、清休息，再能移动及执行原生动作。醒来仍按原生效果，不强行把疲劳设为0。 |

本轮增加[床/沙发策略和预约](../reviews/2026-10-24/repose-sites.md)。在据点内右键床/沙发的本模组菜单设置公共、指定NPC或禁止NPC：两NPC争用时睡眠只允许一个整件预约；专用成员离开仍不开放；禁止NPC后改选其他设施或地面。预约途中及睡眠中修改策略/拆除家具，确认旧NPC醒来停止后才释放，不抢玩家实际使用。正常保存重进应保持整件策略，重新核对家具身份及原任务恢复；同坐标新家具不继承旧预约。家具坐卧动画未适配，不以姿势判断效果。原生疲劳不下降、玩家界面被影响、醒后不能动作任一发生，都应记录为睡眠原型失败，不用宿主回归或“有动画”替代。

0.25.1增加[所属据点共享选床](../reviews/2026-10-24/settlement-repose-discovery.md)：将可用床放在距NPC超过10格处，以及有正常楼梯连接的楼上/地下，保持同一据点范围；核对找到原床、正常走到床边、预约唯一并实际降低疲劳。另放其他据点的床与专属他人的床，确认不借用。区域未加载时不得假报已确认无床；重新加载后应重新发现。发现跨层床不等于楼梯必然可达，路径失败应冷却并尝试替代。

失败时保留console.txt中该NPC附近的SELF_CARE、控制、生产及保存日志，注明发生步骤、原件去向与是否重进；不要先清空任务或重造物品。UNKNOWN会保留事实阻止消费重放和载体删除。此清单不覆盖强退/磁盘故障/联机或性能规模。
