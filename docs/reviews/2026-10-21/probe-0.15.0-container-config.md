# 0.15.0 容器配置体验收尾

日期：2026-10-21；状态：实现与本地必要检查完成，真实游戏新界面未运行。

用户批准轻度实施容器状态、预设、规则复制/粘贴和就地提示。本轮开始读取在线旧哈希，收尾时收到用户更新指示，已按[当前差异](requirements-update.md)登记新正文；本切片不与新增约束冲突。

ContainerConfiguration负责预设、规则克隆、世界/玩家会话剪贴板及只读摘要；ContainerConfigControls负责组合框/按钮/缓存摘要；ContainerMenu统一世界和物品栏侧栏入口。复用现有FilterEditor/Layout/Text/State/Theme。提供食品/耐存/生鲜、军械、医疗、工具、材料、废品八类预设；预设和粘贴先进入草稿，Apply才提交，保留目标的私人/停用标志和物流用途。取消不写世界。Registry.configure新增可选用途，在单次配置通知前同时提交过滤与用途，不发两次中间状态事件。

编辑器及悬停显示用途、共享/私人/停用、允许/排除类别与类型特例计数，默认提示入库只供货、目标无规则或私有/停用等；菜单行按屏幕宽度截断，避免长说明撑大右键菜单。界面绘制不扫库存；打开编辑器仍沿用原有最多2000件/128类型的候选采集。复制只读配置，编辑权限和Apply时邻近/对象/加载门禁保留，跨世界剪贴板失效，不访问OS剪贴板。

本地结果：完整preflight通过，70个Lua语法0错误/警告；LuaLS0错误、2条信息警告（原有Debug函数替换，以及控件按生命周期分阶段初始化）。release-check0错误/提示。当前安装Kahlua/stdlib内小范围检查了私有/停用保留、来源/目标无共享表别名、预设替换、剪贴板克隆/跨世界失效、实际CN摘要；未跑历史全量Lua回归。构建脚本内置Java冒烟随版本JAR生成运行，未启动游戏。原始记录见build/logs/0.15.0-*。

使用：右键世界容器“余烬商路 → 容器设置”，或右键物品栏容器图标“容器设置”，进入编辑；选用途、预设或粘贴后点原版“应用”。菜单复制已保存规则，编辑器复制当前草稿。真实游戏的新布局、原版/其他UI模组组合及输入交互仍待日常使用确认。
