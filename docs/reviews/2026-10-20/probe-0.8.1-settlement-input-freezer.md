# 0.8.1 据点输入、入口与冰柜修复

日期：2026-10-20；主代理独立实施；新实机待验证。

用户确认0.8.0步骤1可用，步骤2找不到仓储菜单，名称输入点击重新划区，冰柜没有过滤入口。console.txt可见0.8.0一次SETTLEMENT SAVED，不能据此断言范围正确或盘点通过。

原因与变化：

- 旧菜单只枚举玩家所在区域；改为列出自有据点，范围外显示原有本地化原因，点击允许编辑追加范围；盘点继续通过Ledger.view校验范围与归属。
- 划区outside回调未检验鼠标是否位于窗口/子控件区域。按当前原版ISUIElement的getAbsoluteX/Y做实际窗口边界校验；拖动进入窗口也不更新世界范围。
- 旧容器栏明确排除副容器。按当前安装ISInventoryPage的getContainerCount/getContainerByIndex(0基)逐格接入；世界菜单与容器栏均传递实际容器。筛选面板、登记/恢复、权限、目标接收和物理搬运均使用该端点。主格与副格独立配置、ID与变更通知；旧主格标记和无索引坐标记录保持兼容。
